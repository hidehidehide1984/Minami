# Minami

横浜市立南高校附属中（南附属中）の適性検査むけ学習アプリ置き場です。

## 📦 収録アプリ

### 南中チャレンジ 🦉 — [`yokohama-minami-quiz-app/`](./yokohama-minami-quiz-app/)

小6向けの 1問1答 適性検査 練習Webアプリ（インストール不要・サーバー不要）。
詳しくは [アプリの README](./yokohama-minami-quiz-app/README.md) を参照してください。

## 🌐 URLで開く（GitHub Pages）

`.github/workflows/deploy-pages.yml` により、対象ブランチへ push すると
GitHub Pages へ自動デプロイされます。公開URLは次の通りです。

**https://hidehidehide1984.github.io/Minami/**

> 初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を
> **「GitHub Actions」** に設定してください（ワークフロー側でも自動有効化を試みます）。
> デプロイの状況は **Actions** タブで確認できます。

## 🖥️ ローカルで開く

URLを使わず、手元で開くこともできます。

```
yokohama-minami-quiz-app/index.html
```

を、そのままブラウザでダブルクリックして開くだけで動きます。
