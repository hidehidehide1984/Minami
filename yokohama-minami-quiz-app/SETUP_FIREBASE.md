# ☁️ クラウド同期のセットアップ手順（Firebase）

所要時間は約10分。費用は**無料**です（Firestoreの無料枠で十分足ります）。
この設定をすると、スマホ・タブレット・PCで学習記録を同期できます。

## 1. Firebaseプロジェクトを作る

1. https://console.firebase.google.com/ を開き、Googleアカウントでログイン
2. **「プロジェクトを追加」** をクリック
3. プロジェクト名に `minami-quiz` など好きな名前を入力 → 続行
4. 「Googleアナリティクス」は **無効（オフ）** でOK → **「プロジェクトを作成」**

## 2. Firestore データベースを作る

1. 左メニューの **「構築」→「Firestore Database」** を開く
2. **「データベースを作成」** をクリック
3. ロケーションは **`asia-northeast1`（東京）** を選択
4. **「本番環境モード」** を選んで作成

## 3. セキュリティルールを設定する

1. Firestore の **「ルール」** タブを開く
2. 中身を**ぜんぶ消して**、次を貼り付け → **「公開」**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 学習記録：同期コード（ドキュメントID）を知っている人だけ読み書き可
    // 一覧の取得と削除は禁止（コードを知らない人は何も見えない）
    match /progress/{code} {
      allow get: if true;
      allow create, update: if request.resource.data.keys().hasOnly(['data', 'updatedAt'])
        && request.resource.data.data is string
        && request.resource.data.data.size() < 300000;
      allow list, delete: if false;
    }
  }
}
```

## 4. 設定値（2つ）を取得する

1. 左上の **⚙️（歯車）→「プロジェクトの設定」** を開く
2. 「全般」タブの下の方、**「マイアプリ」で `</>`（ウェブ）** をクリック
3. アプリのニックネームは何でもOK（例 `minami-web`）。Hostingは**チェック不要** → 登録
4. 表示されるコードの中から、次の2つをコピー
   - `apiKey: "AIzaSy..."`
   - `projectId: "minami-quiz-xxxxx"`

## 5. アプリに設定値を入れる

**方法A（かんたん）**: この2つの値をClaudeに伝える → コミットして公開まで実施します。

**方法B（自分で）**: GitHubで `yokohama-minami-quiz-app/js/firebase-config.js` を開き、
えんぴつ（編集）アイコンから2つの値を貼り付けてコミット。push後に自動デプロイされます。

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIzaSy...ここに貼る...",
  projectId: "minami-quiz-xxxxx",
};
```

## 6. 使い方（設定完了後）

1. 1台目：アプリの **⚙️せってい → ☁️クラウド同期 → 「新しくはじめる」**
   → 同期コード（例 `minami-K7F3-QX9A-M2TD`）が作られます。**メモしてください**
2. 2台目：**「コードを入力」** で同じコードを入れる → 記録がつながります
3. 以後は自動同期（問題を解くと数秒後に保存、起動時に最新を取得）

## 6.5 保護者の「みまもり」画面（閲覧専用）

お子さんのスマホで勉強し、その様子を保護者のタブレット等から**見るだけ**したい場合：

1. お子さんのスマホで ⚙️せってい → ☁️クラウド同期 → **「👨‍👩‍👧 みまもりURLをコピー」**
   → 例：`https://hidehidehide1984.github.io/Minami/mimamori.html?code=minami-XXXX-XXXX-XXXX`
2. そのURLを保護者のタブレットに送り、**ブックマーク**しておく
3. ひらくだけで、**今週の学習日数・問題数・正答率・分野別の伸び・カレンダー・合格めやす・褒めポイント**が見られます

- **閲覧専用**なので、タブレット側でお子さんの記録を誤って変えることはありません（問題も出ません）。
- 1分ごとに自動更新。🔄ボタンでもすぐ更新できます。
- （URL手打ちでもOK：`mimamori.html` を開いてコードを入力）

## ❓ 困ったとき

- **「つながらなかった…」と出る** … firebase-config.js の2つの値、手順3のルール公開、ネット接続を確認
- **同期コードを忘れた** … 同期中の端末の ⚙️せってい に表示されています
- **同期をやめたい** … ⚙️せってい → 「同期をやめる」（記録は消えません）

## 🔒 プライバシーについて

- クラウドに送るのは学習記録（XP・正答率・解いた問題の記録・ニックネーム）だけです。氏名・メールアドレスは送りません
- 同期コードが実質のパスワードです。**家族以外に教えないでください**
- コードは推測できないランダムな文字列（約60ビット）で、一覧取得はルールで禁止しています
