# 南中チャレンジ 🦉 — 横浜市立南高校附属中 適性検査 1問1答アプリ

横浜市立南高等学校附属中学校（南附属中）の **適性検査** で問われる力を、
小学6年生が**毎日少しずつ・一人でも続けられる**ように作った 1問1答の学習Webアプリです。

- インストール不要・サーバー不要・無料
- `index.html` をブラウザで開くだけで動きます（スマホ・タブレット・PCどれでもOK）
- 学習データはブラウザ内（localStorage）に自動保存。続きから再開できます

> ⚠️ 収録問題は、南附属中の出題傾向（適性検査Ⅰ・Ⅱ）に合わせて作った
> **オリジナルの練習問題**です。本番の過去問そのものではありません。

---

## つかいかた

1. このフォルダを丸ごとダウンロード/コピーする
2. `index.html` をダブルクリックしてブラウザで開く
3. 「▶ 今日の問題をはじめる」を押すだけ

最初に右上の ⚙️ から **なまえ** と **1日の目標問題数** を決めておくと、やる気が出ます。

## 南附属中の入試にどう対応しているか

適性検査の傾向（[参考](#参考)）に合わせ、出題を **8分野** に分けています。
分野ごとに正答率を記録するので、**得意・苦手が見える化**されます。

| 分野 | 入試での位置づけ |
|---|---|
| 📝 ことば・漢字 | 適性Ⅰ：言語・語句 |
| 📖 読み取り | 適性Ⅰ：文章・資料・グラフの読み取り |
| 🔢 数と規則 | 適性Ⅱ：数の性質・規則性 |
| 📐 図形 | 適性Ⅱ：面積・体積・角 |
| ⚖️ 割合・速さ | 適性Ⅱ：割合・速さ・場合の数 |
| 🔬 理科 | 適性Ⅱ：理科4分野 |
| 🗾 社会 | 資料分析・一般常識 |
| 🧩 思考力 | 適性Ⅰ前半：パズル・論理 |

## 「出す問題を変える」適応ロジック

`js/adaptive.js` が、回答の記録から次の1問を選びます。

1. **苦手分野を多めに出す** — 分野ごとの正答率（直近重視）が低いほど出題されやすい
2. **まちがえた問題をあとでまた出す** — かんたんな間隔反復（Leitnerの箱・0〜5）。
   正解で次に出るまでの日数がのび（1→2→4→7→14日）、まちがえると箱が0に戻ってすぐ復習
3. **得意になったら難しく** — その分野の正答率が上がると、出る問題の難易度（★1→★2→★3）が上がる
4. **いろいろな分野をまぜる（インターリーブ）** — 同じ分野ばかり続かないようにして飽きを防ぐ
5. **同じ問題を同じ日に連発しない**

苦手は「やや多め」に出しつつ、1分野に偏りすぎないよう調整しているので、
ドリルになりすぎず続けやすくなっています。

## 小6が続けられるための仕組み

`js/gamify.js`

- **レベル／経験値（XP）** … 正解でXPがたまる（難しい問題ほど多い）。100XPごとにレベルアップ
- **連続日数（🔥ストリーク）** … 毎日少しでもやると数字がのびる。さぼると1に戻る
- **デイリーミッション** … 「今日は○問」。達成すると応援メッセージ＆バッジ
- **バッジ（全10種）** … 「3日連続」「50問正解」「全分野に挑戦」などを集める楽しさ
- **2週間カレンダー** … がんばった日が色づいて見える
- **すぐほめる** … 1問ごとに正解の演出・解説。まちがえても挑戦XPが少し入る

### 適性検査チャレンジ（記述・自己採点）

1問1答の基礎ドリルに加えて、本番に近い **長文読解＋記述（適性Ⅰ型）** や
**資料・グラフ・算数理科＋記述（適性Ⅱ型）** の問題を `js/challenges.js` に収録しています。
記述式なので、書いたあとに **模範解答（例）と採点ポイント** を見て自分でまるつけ（自己採点）します。

> ⚠️ これらも過去問ではなく、本番の出題形式に合わせて書き下ろしたオリジナル問題です。

## 問題の増やし方

`js/questions.js` の `QUESTIONS` 配列に追記するだけです。
小学生がキーボード入力しなくてよいよう、**すべて4択（`type: "choice"`）**にしています。

```js
{ id: "kazu25", category: "kazu", level: 2, type: "choice",
  q: "問題文…", choices: ["正解", "ダミー1", "ダミー2", "ダミー3"], answer: "正解",
  hint: "ヒント", exp: "かいせつ" },
```

`answer` は `choices` の中の正解の文字列と一致させます。記述（作文）の練習は
`js/challenges.js` の「適性検査チャレンジ」で行います。
